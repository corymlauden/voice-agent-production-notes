# Demo dataset

A synthetic backlog-reactivation campaign. Every name, number, address, and
transcript is fiction, generated by [generate_demo_data.py](generate_demo_data.py).

Why it's built the way it is:

Phone numbers use the 555-01XX block, permanently reserved for fiction. They
read slightly fake, and that's the correct trade for data you show strangers.

It's seeded, so it's byte-identical every run. A demo that changes between
rehearsal and the real thing is a demo that surprises you in front of someone.

The disposition mix is modeled on a genuinely cold aged list, not a happy
path. Mostly no-answer, a real slice of wrong numbers, a small number of
opt-outs.

Every opt-out in [data/dnc_log.csv](data/dnc_log.csv) carries an audit trail:
which call produced it, when, and the caller's exact words.

## Files

| File | What it is |
|---|---|
| `data/contacts.csv` | 250 synthetic aged contacts with source and age |
| `data/calls.json` | 328 call records with dispositions, attempts, durations |
| `data/transcripts/` | Turn-by-turn transcripts for connected calls |
| `data/appointments.csv` | Booked appointments with prep notes |
| `data/dnc_log.csv` | Do-not-call audit log |
| `data/summary.json` | The campaign numbers at a glance |

Regenerate with:

```bash
python3 generate_demo_data.py --out ./data
```
